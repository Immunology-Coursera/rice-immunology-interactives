# Lesson 1.4 — The Unsung Hero: ungraded practice

Open `index.html` in a browser to preview. This folder contains three self-checks with immediate feedback and retries; no accounts or scoring service.

- **Q1:** Identify blood, interstitial fluid, and lymph at three numbered locations on a cropped portion of the instructor's high-resolution fluid-balance slide.
- **Q2:** Put seven fluid-pathway steps in order (up/down buttons for touch and keyboard accessibility; optional drag-and-drop on desktop).
- **Q3:** Classify bone marrow, thymus, lymph nodes, spleen, and MALT. A cropped anatomical illustration from the uploaded *Lymphoid Organs* slide appears as reference without the answer key.

## Publish to GitHub Pages

1. Create or open a repository and upload **all files**, keeping `assets/` alongside `index.html`.
2. Open **Settings → Pages** and publish from the desired branch and root folder. Allow GitHub Pages to publish.
3. Test the resulting HTTPS URL in a regular browser.
4. In Coursera, embed using the course tool that supports an external iframe. Embedding support and third-party content policies vary; test inside the actual course before rollout.

## Before publication

- Verify Q1 numbered markers with the instructor against the unmodified source illustration. Marker positions are inferred from the image and warrant scientific review.
- Check that the lecture supports the exact terms and ordering in Q2.
- Ensure you have permission to republish slide illustrations (including any underlying third-party artwork) on a public GitHub Pages site. A private/restricted asset route may be preferable if not.
- Check keyboard, screen reader, phone-size rendering, and iframe height inside Coursera.
